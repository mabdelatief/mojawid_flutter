# mojawid_flutter

**Mojawid (مُجَوِّد)** is a free app for practising Quran recitation, with no accounts, for iOS,
Android and the web. The user recites, sees where the recitation differed from the correct
reading, and tries again. Arabic first, right to left. Nothing is built yet.

- [`docs/product.md`](docs/product.md): what the app is, the user's decisions, every screen,
  corrections to the design, and open questions.
- [`design/design_handoff_mojawid/README.md`](design/design_handoff_mojawid/README.md): the
  Claude Design handoff (brand, tokens, screens, copy). It includes screenshots, a clickable
  prototype (`design/Mojawid App.dc.html`) and brand assets.
- The model and how results are made: `mojawid_backend/docs/model-and-analysis.md`
  ([GitHub](https://github.com/mabdelatief/mojawid_backend/blob/main/docs/model-and-analysis.md)).
